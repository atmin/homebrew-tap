# atmin/tap

This Homebrew tap distributes command-line tools from the `atmin` account.

## memcore

```sh
brew install atmin/tap/memcore
```

Homebrew adds the tap on first use. To update memcore, run `brew upgrade atmin/tap/memcore`.

The memcore release workflow updates the formula from the checksums of each stable release. The install guide covers setup, the desktop application and removal. [memcore install guide](https://github.com/atmin/memcore/blob/main/docs/install.md)
